# Write Right AI

تطبيق أندرويد هو **لوحة كتابة بالقلم** بطول الشاشة كلها. بتكتب بإيدك بالإنجليزي، والتطبيق بيراجع كل كلمة وبيصحح الغلط **قدامك على اللوحة نفسها**: بيلف حوالين الكلمة الغلط بخط أحمر ويكتب الصح فوقها بخط أخضر. بتضغط على التصحيح فيشرح لك الغلطة ويسمّعك الكلمة.

الهدف الوحيد: تحسين مهارة **الكتابة** (الإملاء) باللغة الإنجليزية.

الهوية البصرية مأخوذة من WordPop: نعناعي `#2FE0B5`، بوردر سميك، وظل صلب.

---

## الشاشات

| الشاشة | الوصف |
|---|---|
| لوحة فاضية | اللوحة هي الشاشة كلها، فوق زراري "عن التطبيق" وعدّاد الغلطات، وتحت شريط الأدوات |
| تصحيح على اللوحة | دايرة حمرا حوالين الكلمة الغلط والكلمة الصح مكتوبة فوقها |
| اشرح الغلطة | ورقة تطلع من تحت: الغلط والصح، الحروف المتعلّم عليها، نصيحة، زرار نطق، زرار "اكتبها تاني" |

شريط الأدوات: قلم، ممحاة، تراجع، مسح الكل.

---

## إزاي بيشتغل

```
القلم يرسم strokes على اللوحة
        │  (بعد ما تقف عن الكتابة حوالي ثانية)
        ▼
WordSegmenter   يقسّم الـ strokes لكلمات (حسب الخطوط والمسافات)
        ▼
ML Kit Digital Ink Recognition   يقرأ الخط ويطلع نص (أوفلاين)
        ▼
SpellEngine   مدقق الإملاء بتاع الموبايل يقول الكلمة صح ولا غلط ويقترح تصحيح
        ▼
MistakeAnalyzer   يحدد نوع الغلطة (حرفين مقلوبين / ناقص حرف / حرف زيادة ...) ويطلع نصيحة
        ▼
اللوحة ترسم الدايرة الحمرا والتصحيح الأخضر
```

## رفع المشروع على GitHub

1. اعمل Repository جديد على GitHub (فاضي) واسمه مثلاً `WriteRightAI`.
2. افتح Terminal جوه فولدر المشروع وشغّل:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/<اسم-المستخدم>/WriteRightAI.git
git push -u origin main
```

> استخدم `git push` بدل الرفع من المتصفح، لأن فولدر `.github` مخفي وممكن ميترفعش من واجهة الويب.

## بناء ملف الـ APK

أول ما تعمل `push` على فرع `main`، الـ workflow اسمه **Build APK** بيشتغل لوحده.

1. افتح الـ Repository على GitHub واضغط تبويب **Actions**.
2. اختار آخر تشغيل لـ **Build APK**، وانتظر لحد ما يخلص (علامة خضرا).
3. انزل لتحت لقسم **Artifacts** ونزّل **WriteRightAI-debug-apk**.
4. فك الضغط هتلاقي ملف `app-debug.apk`، انقله للموبايل وثبّته (فعّل "التثبيت من مصادر غير معروفة" لو طلب).

تقدر كمان تشغّله يدوي: **Actions ← Build APK ← Run workflow**.

الـ APK ده Debug وموقّع بمفتاح الـ debug، يعني مناسب للتجربة. للنشر على Google Play هتحتاج مفتاح توقيع Release.

## أول تشغيل على الموبايل

- **نموذج قراءة الخط:** التطبيق بيحمّل نموذج اللغة الإنجليزية من Google **مرة واحدة**، فلازم إنترنت أول مرة. بعد كده بيشتغل أوفلاين.
- **المدقق الإملائي:** التطبيق بيعتمد على المدقق الإملائي اللي في الموبايل. لو ظهر تنبيه "المدقق الإملائي مقفول"، فعّله من إعدادات الموبايل: *اللغة والإدخال ← المدقق الإملائي* (المسار بيختلف حسب الشركة المصنّعة) واختار Google.
- **النطق:** بيستخدم محرك Text-to-Speech بتاع الموبايل، وبيحتاج صوت إنجليزي (US) منزّل.

## نصايح للكتابة عشان القراءة تطلع دقيقة

- اكتب كل كلمة **بين الخطوط**، لأن التطبيق بيعتبر كل سطر مستقل.
- سيب **مسافة صغيرة** بين الكلمات، لأن بيفصل الكلمات بالمسافة.
- اكتب بخط واضح ومنفصل (print) أحسن من الخط المتصل.

## حدود معروفة

- **أهم نقطة تتجرّب الأول:** نموذج قراءة الخط فيه نموذج لغة، وممكن "يتصحح لوحده" ويقرأ `recieve` على إنها `receive`، فالغلطة متتمسكش. لو لاحظت ده كتير، الحل التالي هو قراءة كل حرف لوحده بدل الكلمة كلها.
- لو القراءة غلطت في كلمة (قرأتها غلط وإنت كاتبها صح)، اضغط **أنا كاتبها صح** وهتتجاهل الكلمة دي.
- الأسماء والاختصارات ممكن المدقق يشوفها غلط.
- مفيش حفظ للوحة أو لسجل الأخطاء لسه.

## تخصيص

- **ألوان الهوية:** `ui/Theme.kt` (الكائن `Brand`).
- **حساسية الفصل بين الكلمات والسطور:** `board/Models.kt` (الكائن `BoardMetrics`).
- **مدة الانتظار قبل المراجعة:** `delay(900)` في `board/BoardViewModel.kt`.
- **لهجة الإنجليزي:** غيّر `"en-US"` في `BoardViewModel.kt` و`Locale.US` في `SpellEngine.kt` و`Speaker.kt` (مثلاً `en-GB`).
- **الخطوط:** حالياً بتستخدم خطوط النظام. لاستخدام Lalezar وReadex Pro وCaveat: حط ملفات الخطوط (حروف صغيرة وأسماء بدون شرطات) في `app/src/main/res/font/` وعرّف `FontFamily(Font(R.font.lalezar))` في `ui/Theme.kt`، واستخدمه في `TextStyle` بدل `FontFamily.Cursive` وخط النظام.

## خطوات جاية مقترحة

1. اختبار دقة القراءة والتصحيح على موبايلك وتعديل الحساسية.
2. حفظ الأخطاء المتكررة وعرض "بتغلط فيها كتير".
3. وضع تدريب: التطبيق ينطق كلمة وإنت تكتبها على اللوحة.
4. تصحيح جمل كاملة (قواعد وأسلوب) بالـ Claude API.
